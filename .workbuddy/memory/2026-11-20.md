# 2026-11-20

## WorkBuddy 技能包两级目录限制修复

- 现象：开放平台上传 `yss-ui-component-docs.zip` 报「解析失败：目录层级超限 — Skill 包仅支持两级目录结构（根目录/二级目录/文件）」。根因是包内 `references/mcp-data/*.json` 与全部聚合包的 `references/deps/<skill>/...` 都有二级子目录。
- 修复：重构 `scripts/pack-workbuddy-skills.mjs`
  - 成员技能正文平铺为 `references/dep-<skill>.md`，附属文件平铺为 `references/dep-<skill>--<path>.md`（去掉重复的 `references/` 段）。
  - 正文引用统一改写为包根相对写法 `@references/xxx`；目录引用改写为 `@references/<前缀>--*`；主技能自身资源仍保留 `references/xxx.md` 两级结构。
  - 主技能 SKILL.md 只在包根写一次，其它技能指向它的引用写 `@SKILL.md`。
  - 新增 zip 段数校验（≤3 段，即包名/子目录/文件）、平铺文件名冲突校验、`@...` 引用闭合校验。
  - 组件文档速查包的数据文件改为平铺 `references/{index,schemas,coverage-summary}.json` 并同步正文。
- 结果：11 个 zip 全部 maxSeg ≤ 3（`yss-theme-token` 为 2），体积 3.9KB–377KB。
- 平台规则：一个 zip = 一个技能，多个技能须分别「创建」提交（每步只能选 1 个文件），注意每日配额。
