# 组件总览

YSS UI 提供面向企业中后台场景的组件集合，按「通用、表单、表格、图表、业务」五类组织。

## 学习路径

- 新接入项目：先看 [Button](/components/button)、[Card](/components/card)、[Table](/components/table)
- 表单场景：看 [Formily](/components/formily) 与 [Cron](/components/cron)
- 丰富交互：看 [MonthCalendar](/components/month-calendar)、[FilePreview](/components/file-preview)
- 复杂业务：看 [ConditionBuilder](/components/condition-builder)、[FileImport](/components/file-import)

## 快捷入口

- 通用组件：`Button`、`Card`、`ConfigProvider`、`SplitPane`、`Tree`、`MonthCalendar`、`FilePreview`
- 表单组件：`Formily`、`Monaco`、`Cron`
- 表格组件：`Table`、`EditTable`、`Sheet`
- 图表组件：`Echarts`
- 业务组件：`ConditionBuilder`、`FileImport`
