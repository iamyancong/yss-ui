# @yss-ui/create 更新日志

`@yss-ui/create` 与别名包 `create-yss-app` 版本同步，共用本更新日志。

## v1.3.2

`2026-10-13`

### ⚠️ 行为变化与升级说明

- **默认包管理器对齐 pnpm**：未显式传 `--pm` 时默认使用 pnpm（与模板 workspace 一致），结尾安装与启动命令统一提示 pnpm (#56)。
- **activeRule 展示完整路径**：激活路由提示及 `micro-config.json` 的 `app.activeRule`、`app.entry` 统一展示完整 `/subApp/<name>` 路径 (#56)。

### 🐛 Bug Fixes

- **环境变量改写**：遍历改写 `packages/` 下实际存在的所有 `.env*` 文件（消除模板残留与 JSP mdm 默认值），且绝不凭空创建模板中原本没有的文件 (#56)。
- **Lockfile 维护与竞争态**：刷新超时主动杀死子进程并等待其彻底退出后再删除旧锁文件，解决异步写回竞争态；超时时间放宽至 45 秒并收敛提示文案 (#56)。
- **npmmirror 镜像源兜底与稳定性增强**：公共镜像兜底前先确认镜像内已同步该版本，未同步则保留模板原版本；增加包元数据查询 1 次超时重试以消除偶发网络抖动；模板已声明最新版本时不再输出误导性兜底或滞后警告 (#56)。

### 🧪 Tests

- 快照测试统一固定端口为 18081，消除 CI 多进程并行端口探测导致的偶发失败 (#56)。

## v1.3.1

`2026-10-13`

### ⚠️ 行为变化与升级说明

- **实时检查新版本**：移除 24 小时本地缓存，每次交互运行实时向 registry 查询最新版本（超时 1.5 秒），发版后即时提示 (#55)。
- **确认框默认切换**：发现新版本时的确认框默认选中「是」，直接回车即可通过 npx 切换到新版本运行 (#55)。

### 🐛 Bug Fixes

- **下载失败优雅降级**：区分 npx 下载阶段失败与新版本运行期报错；下载失败时告警并自动退回当前版本继续创建 (#55)。
- **双包版本同步**：发版脚本将别名包 `create-yss-app` 与 `@yss-ui/create` 绑定同步发版与依赖对齐 (#52)。

## v1.3.0

`2026-10-13`

### ⚠️ 行为变化与升级说明

- **依赖自动升级**：生成后自动扫描 `package.json` 并将 `@yss-ui/*` 升级至当前 registry 最新版，保留原版本前缀；传 `--no-sync-deps` 可关闭 (#53)。
- **锁文件自动刷新**：依赖升级后自动刷新 `pnpm-lock.yaml`，刷新失败则安全删除旧锁文件避免冲突 (#53)。
- **默认同步 Skills**：生成后默认联网同步最新 AI Skills，超时 120 秒且失败不阻断创建；离线可传 `--no-skills` (#54)。

### 🚀 Features

- **镜像落后保护**：公共镜像（npmmirror）尚未同步官方最新版时，自动回退到镜像支持的最高版本，绝不降级或写入不可用版本 (#53)。
- **交互与机器输出优化**：预览表新增「依赖版本」源地址；`--json` 输出新增 `dependencyUpdates`、`lockfile` 与 `skills` 字段 (#53, #54)。

### 🐛 Bug Fixes

- 统一由 CLI 负责 skills 同步与「下一步」提示，消除重复警告与多份引导 (#53, #54)。
- 修复交互模式下部分警告信息未能正常输出的问题 (#54)。

## v1.2.0

`2026-10-12`

### 🚀 Features

- **版本号显式展示**：交互模式标题与 stderr 显式展示 CLI 版本，`--json` 输出新增 `cliVersion` 字段 (#52)。
- **新版本检测与引导**：启动时后台异步查询最新版本；交互模式支持选「是」自动通过 npx 切至新版运行，非交互模式结尾提示升级命令 (#52)。

### 📝 Documentation

- 别名包 `create-yss-app` README 补充始终带上 `@latest` 运行说明；常见问题新增旧版本缓存清理指南 (#52)。

## v1.1.0

`2026-10-12`

### ⚠️ 行为变化与升级说明

- **默认公开模板**：默认模板地址切换为 GitHub 公开仓库 `microapp-template-vue3`（main 分支），支持 `--template-url` 覆盖 (#51)。
- **移除 OpenAPI 交互提问**：交互向导不再询问 OpenAPI 地址，需要时通过 `--openapi-url` 传入 (#51)。
- **非交互凭据防护**：`--yes`、`--json` 等非交互模式禁用 git 交互提问，缺少凭据立即退出（退出码 5）(#51)。

### 🐛 Bug Fixes

- **拉取错误诊断**：精简 git 报错日志，分类输出认证失败、仓库不存在或网络不可达等精准诊断 (#51)。
- 修复交互模式下模板拉取失败时 loading 动画未正常收尾的问题 (#51)。

## v1.0.0

`2026-10-10`

### 🚀 Features

- **初始发布**：企业级微应用一键脚手架 CLI（`@yss-ui/create` 与别名包 `create-yss-app`）。
- **activeRule 命名规范**：对齐雨燕驼峰命名规则，支持从应用英文名自动推导单段路由。
- **Core 模块共享**：与 `yss-create-microapp` AI Skill 共享零外部依赖 core 核心，生成结果逐文件一致。
- **自动化模式**：支持 `--dry-run`、`--json`、`--plan-out` 与 `--apply` 离线可审阅计划执行。
- **严格参数校验**：未知参数、格式非法或目标目录已存在均输出明确退出码与中文指引。
