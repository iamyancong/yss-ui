# create-yss-app

[`@yss-ui/create`](https://www.npmjs.com/package/@yss-ui/create) 的别名包，用于支持 `npm create yss-app` / `pnpm create yss-app` / `yarn create yss-app`。

```bash
npm create yss-app@latest
```

参数与行为完全等同于 `npx @yss-ui/create`，详见 [微应用创建 CLI](https://iamyancong.github.io/yss-ui/guide/create-app)。不收集任何遥测数据。
